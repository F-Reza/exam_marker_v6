# Exam Marker V4 — Full Role and Plan System

## Authenticated roles
- Super Admin: platform plans, accounts, assignments, limits and all dashboards.
- Coaching Admin: Mode 3 organisation management, students, parents, teachers and communications.
- Teacher: assigned-paper workspace, marking, editing and finalisation according to plan.
- Student: personal result portal with only their linked papers.

## Plan permissions
- Free: one lifetime check and online basic result.
- Mode 1: individual marks and history, no bulk upload/downloads.
- Mode 2: analytics, bulk upload/import, manual editing, recheck and result report; no corrected-paper download, parent data or multiple teachers.
- Mode 3: all Mode 2 features plus corrected-paper download, parent communication, multiple teachers and teacher assignment.

## Demonstration integrations
The included demo marker makes the end-to-end workflow testable without API keys. Production OCR, live AI, payment gateway, SMS/WhatsApp and transactional email require provider credentials.
