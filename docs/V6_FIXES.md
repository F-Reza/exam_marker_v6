# V6 functional fixes

1. The system is subject-neutral. English, Humanities and source-based assessments are supported.
2. QP and optional MS remain on the same step. A separate optional Insert/Source Booklet upload accepts up to five PDF/DOC/DOCX files.
3. Subquestions such as 1(a), 1(b) are stored as separate question results and the result view calculates a cumulative score for the main question.
4. Mode 2 bulk upload now accepts an existing student or a typed student name for every WA.
5. Mode 3 parent email includes a generated PDF report and secure expiring online report link. The public parent view can download the PDF.
6. The old static demo score pattern is replaced by an adaptive local marker that actually reads the uploaded PDF/DOC/DOCX text and produces different scores based on response completeness and mark-scheme/key-point overlap. It remains heuristic and must not be treated as a replacement for a production AI/OCR provider.
7. SVG favicon included.
8. Paid plan buttons lead to checkout. Super Admin can configure PayPal, PayU, PhonePe and Paytm settings.
