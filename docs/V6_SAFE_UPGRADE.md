# V6 incremental upgrade and release

Use this procedure for the merged remediation. The earlier document-only ZIP did not contain the processing-attempt migrations and is superseded by this branch.

1. Back up the database and private uploads. Preserve the deployed `.env` and encryption key.
2. Install locked dependencies: `composer install --no-dev --optimize-autoloader`. PHP 8.2+, XML/DOM, zip, mbstring, fileinfo, GD, PDO and process execution are required. Typed Word 97-2003 and DOCX use the bundled PHP readers. Other legacy DOC variants may need antiword/LibreOffice; scanned PDF needs Poppler/Tesseract.
3. Run **`php artisan migrate --force`**. Never run `migrate:fresh` against existing data. The three 10 November migrations add attempt identities, optional mobile/subscription fields and student invitations. Existing paid owners receive a transition month from migration time; later terms require verified payment or an explicit admin assignment.
4. Run `php artisan optimize:clear` and `php artisan queue:restart`. Restart persistent PHP workers after code deployment. Queue worker timeout is 180 seconds and database retry-after is at least 240 seconds. Run a worker and Laravel's scheduler for asynchronous mode and stalled-attempt recovery.
5. Use `APP_ENV=production`, `APP_DEBUG=false`, HTTPS and private storage permissions. The demo seeder creates demo accounts only in local/testing, does not reset existing accounts or configured plans/gateways, and is not a production admin provisioning tool. After initial plan seeding, provision an admin with `php artisan exam-marker:create-admin your-admin@example.com`; the password is prompted privately.
6. Existing unverified non-admin users must verify their email. Test SMTP, password reset, verification and a student invitation before enabling public registration. Account/organisation inactivity is checked on every session request.
7. INR checkout uses the authenticated PayU adapter. PayPal is hidden for INR; changing the configured pricing currency requires corresponding real plan prices and supported merchant currency. PhonePe, Paytm, bKash and card adapters remain unavailable and cannot be enabled until implemented and verified. Validate real merchant sandbox success/failure/cancellation and model/provider settings before public launch.
8. Test a mixed-format upload in Mode 1 and Mode 2, a bulk batch, approved report delivery, expiring links and the manual monthly renewal flow. Image-only Word files need OCR or a selectable-text copy. Unknown question maxima produce an actionable error, never invented marks.
9. Build a source-only release with `powershell -File scripts/New-Release.ps1 -Name exam-marker-v6-release.zip`. It excludes `.env`, Git history, SQL/SQLite databases, private storage, logs, compiled caches, vendor and node_modules, and clears example secret assignments. Install dependencies on the deployment host.

Quota policy: each successfully validated/stored upload reserves one check, including a failed processing attempt. Deleting a paper does not refund that reservation. Retry or replace documents on the same failed paper without another check. Bulk validation/storage is atomic; processing failures are individual outcomes after the valid batch has committed. Monthly limits follow the subscription anniversary; Free remains one lifetime check. Delivery limits count accepted send attempts, including failures; disabled channels do not consume a send attempt.

Subscriptions are manually renewed monthly terms, not automatic recurring charges. Cancellation preserves access until expiry. Expired accounts use Free entitlements; old paid transaction history is retained. Official exam-board/session grade boundaries and real marking accuracy require examiner confirmation; the local marker always reports provisional suggestions.

Repository hygiene: `.env`, `env.txt` and the SQLite file were previously tracked. Excluding them from new releases does not erase earlier Git history. Keep credential files private and rotate credentials if that earlier history/archive was shared. Do not publish the old archive as the new release.
